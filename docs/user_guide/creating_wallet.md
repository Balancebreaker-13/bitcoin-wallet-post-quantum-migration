# Creating a Wallet

The wallet workflow is built around `HybridWallet`, which combines a Bitcoin-compatible ECDSA key with a post-quantum ML-DSA key.

## Instantiate the wallet

```python
from src.hybrid import HybridWallet

wallet = HybridWallet()
```

## Generate a keypair

```python
public_key = wallet.generate_hybrid_keypair()
private_key = wallet.get_private_key(public_key.key_id)

print(public_key.key_id)
print(public_key.ecc_pubkey.hex())
print(public_key.pqc_pubkey.hex()[:32])
```

## What is created

Each generated wallet key includes:

- `ecc_pubkey`: compressed secp256k1 public key
- `pqc_pubkey`: ML-DSA public key
- `key_id`: stable hash of the key material
- `created_at`: timestamp generated by the wallet clock

The private material is stored in memory until an encrypted key store is used.

## Serializing public keys

```python
public_data = public_key.to_dict()
restored = type(public_key).from_dict(public_data)
assert restored == public_key
```

## Serializing private keys

```python
private_data = private_key.to_dict()
restored_private = type(private_key).from_dict(private_data)
assert restored_private == private_key
```

## Removing keys

```python
removed = wallet.remove_key(public_key.key_id)
assert removed is True
assert wallet.get_public_key(public_key.key_id) is None
```

## Best practices

- Store private keys only in encrypted storage
- Keep `key_id` values stable for wallet recovery and transaction signing
- Treat the PQC layer as the quantum-resistant component; ECDSA remains for compatibility
