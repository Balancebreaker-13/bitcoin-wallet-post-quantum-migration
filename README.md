# bitcoin-wallet-post-quantum-migration
MIGRATION OF BITCOIN WALLETS TO POST QUANTUM CRYPTOGRAPHY WALLETS
THIS PROJECT IS PURELY FOR MIGRATING THE EXISTING CRYPTO WALLETS WITH BITCOINS TO NEW POST QUANTUM CRYPTOGRAPHY BITCOIN WALLETS 
THE PROJECT IS TO STABLE THE BITCOIN MARKET WITHOUT PRICE SWINGS 
THE MAJOR PANIC IN BITCOIN MARKET IS HIGH VOLATILITY DUE TO SUDDEN PRICE CHANGES AND CONCEPTS OF "SATHOSI WALLETS" AND "POST QUANTUM CRYPTOGRAPHY"
NO BLUFF , PURE IDEA FOR GREATER BORDERLESS ECONOMY WITH MINIMAL TRANSACTION FEES
